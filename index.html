Sodium Bicarbonate (NaHCO₃ / Sodib)
Base Deficit (mEq/L, from ABG)
Practical Method (initial dose, 50% of deficit)
—
0.3 × Base Deficit × Weight ÷ 2 | Give half now, reassess ABG before completing correction
Standard Formula (full deficit)
—
0.3 × Base Deficit × Weight | Verified textbook formula — this is what the practical method above halves
⚠️ The Practical Method already includes a built-in 50% safety reduction — don't halve it again. Target pH 7.2, not full normalization, in the first 24hr. Recheck ABG before giving the remainder.
Potassium Deficit
Measured K⁺ (mmol/L)
Standard Formula (deficit only)
—
[4 − K] × Weight/2 | Textbook estimate (extracellular-based)
Deficit + Daily Requirement
—
Deficit (above) + maintenance 1mmol/kg/day | More realistic for 24hr replacement planning
⚠️ These methods can disagree significantly, and none should be treated as a precise number. Total body K⁺ is ~98% intracellular, so serum value alone underestimates true deficit, especially when K < 3. Use clinical judgment, replace gradually, and titrate to repeat measurements rather than any single calculated figure.
Replace via central line at 10mmol/hr (max 20mmol/hr) | 1 amp = 20mmol

SVT Management & Adenosine (Adecard) Protocol
If SVT:
  1. Stop any inotrope
  2. Start Carotid Sinus Massage
     If not improved →
  3. Inj. Adecard 6mg IV flash (CI: Bronchial Asthma)
     Observe 2-3 min → if not resolved:
     Flash 2 amp (12mg), observe 5 min → if not resolved:
     Flash 2 amp (12mg), observe 2-5 min → if no improvement:
     ⚡ DC Shock

Standard doses:
  Peripheral vein: 6 → 12 → 12mg
  Central / CCB / BB: 3 → 6 → 6mg
  Each dose: rapid IV flash, FLUSH 20ml NS immediately
  T½ = 30 sec | Wait 2 min between doses | CI: Asthma, Heart block
